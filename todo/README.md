# 今日のTo-Do帳

- 画面: https://claude.ai/artifact/Vy9HGvo2QPF1oP8nvZJ55A （本人のみ閲覧可・自動保存）
- ソース: `index.html`（変更したら同じURLへ再公開）

## リマインド（Claude Code ルーティン）

| 名前 | 時刻（日本時間） | 内容 |
|---|---|---|
| To-Do 朝のリマインド | 毎日 7:47 | 持ち越し・今日・今後3日のタスクをプッシュ通知 |
| To-Do 夜の未完了チェック | 毎日 20:48 | 今日できていない分と完了件数をプッシュ通知 |

時刻の変更・停止は claude.ai の Routines 画面から行えます。

## 使い方

1. タスクを入力し、期限（今日／明日／1週間後）・分類・優先度を選んで「追加」
2. 終わったら左の丸をタップで完了
3. 期限を過ぎた未完了は「持ち越し」欄に赤字で日数付きで表示。「今日へ」「明日へ」で期限を付け替え

## PCですぐ開く

- claude.ai のサイドバーにピン留め済み
- デスクトップ用ショートカット：Windows は `今日のTo-Do帳.url`、Mac は `今日のTo-Do帳.webloc` をデスクトップに置いてダブルクリック
- ブラウザのブックマークバーに登録（Ctrl+D / ⌘+D）
