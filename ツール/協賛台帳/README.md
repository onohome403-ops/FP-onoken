# 25周年記念大会 協賛台帳

親の会で協賛先への声かけ状況（打診中・承諾・保留・お断り）を共有し、同じ先に重複して声をかけないための台帳です。

## ファイル

| ファイル | 内容 |
|---|---|
| `協賛台帳ページ.html` | Claudeのアーティファクト（共有ページ）版。声かけ前の重複検索、状況の更新、集計、LINE報告文のコピーができます。データ保存にClaudeのアーティファクト機能（db）を使うため、claude.ai上で公開したときだけ動きます。 |
| `協賛台帳.xlsx` | Googleスプレッドシート版の元ファイル。Googleドライブにアップロードするとスプレッドシートに変換されます。 |
| `スプレッドシート作成.py` | `協賛台帳.xlsx` を作るスクリプト（`python3 スプレッドシート作成.py`、openpyxlが必要）。 |

## スプレッドシート版の使い方

1. `協賛台帳.xlsx` をGoogleドライブにアップロードし、「Googleスプレッドシートで開く」で変換する
2. 共有設定を「リンクを知っている全員」「編集者」にする
3. URLをグループLINEに貼る（グループの外には出さない）

主な機能：

- 「区分」「状況」「入金」はプルダウン選択
- 状況ごとに行を色分け（緑＝承諾、黄＝打診中、紫＝保留、赤＝お断り）
- 同じ協賛先を2回登録すると、I列に「⚠重複」と表示され、名前のセルが赤くなる（「(株)」「株式会社」や全角・半角の違いは無視して照合）
- 上部に件数と承諾額・入金済額を自動で集計
- 「使い方」タブに親の会の運用ルール
