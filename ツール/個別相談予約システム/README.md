# 個別相談 予約システム

Googleカレンダーと連携した、**オンライン個別相談**の予約ページです。Google Apps Script（GAS）で動くので、サーバー代・月額費用はかかりません。

## できること

- お客様は公開URL（LINEやインスタのプロフィールに貼る）から、空いている枠だけを見て予約できる
- **Googleカレンダーに予定が入っている時間帯は自動で非表示**（予定の詳細はお客様には見えない）
- 予約が入ると、**Zoom会議を自動発行**し、カレンダーに「【個別相談】◯◯様（オンライン）」の予定を作成（場所欄にZoomのURL）
- お客様にZoomの参加URL入りの確認メール、自分に通知メールを自動送信
- Zoomの発行に失敗しても予約は受け付け、自分宛ての通知メールで「URLを手動で送ってください」とお知らせ
- 同時に同じ枠を押された場合も、後の人には「埋まりました」と表示（ダブルブッキング防止）

## 受付ルール（初期設定）

| 項目 | 設定 |
|---|---|
| 予約方法 | オンラインのみ（対面は自分でカレンダーに直接入れる） |
| 枠 | 毎日 10:30／13:00／14:30／16:00／17:30／19:00／20:30 開始、各90分 |
| 終日休み | 第1・第3月曜日 |
| 火曜日 | 10:30枠なし |
| 予約締切 | 開始の24時間前まで |
| 表示期間 | 今日から30日先まで |
| 終日の予定 | 「休み」などの終日予定がある日は予約不可（「誕生日」「祝日」を含むものは無視） |

ルールはすべて `Code.gs` 冒頭の `CONFIG` で変更できます。

## セットアップ手順（15分ほど＋Zoom設定10分）

1. **https://script.google.com** を開き、「新しいプロジェクト」を作成。名前は「個別相談予約」など
2. 左の歯車（プロジェクトの設定）→「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック
3. エディタに戻り、3つのファイルを貼り付け
   - `コード.gs`（最初からある）→ 中身をすべて消して `Code.gs` の内容を貼る
   - `appsscript.json` → `appsscript.json` の内容を貼る
   - 「＋」→「HTML」で **`Index`** という名前のファイルを作り、`Index.html` の内容を貼る
4. `CONFIG` の `OWNER_NAME`（メールの署名に使う名前）などを自分用に書き換えて保存
5. 上部の関数選択で **`testListSlots`** を選び「実行」→ 権限の許可画面で自分のアカウントを選んで許可
   （「このアプリは確認されていません」と出たら「詳細」→「◯◯（安全ではないページ）に移動」）
   → 実行ログに空き枠が出ればOK
6. （Zoomを使う場合）下の「Zoom連携の設定」を先に済ませる
7. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
8. 表示された **ウェブアプリのURL** が予約ページです。LINE・インスタ・名刺のQRコードなどに使ってください

## Zoom連携の設定（10分ほど）

> Zoomの無料プランは1回40分までのため、90分の相談には**有料プラン（Pro以上）**が必要です。

1. **https://marketplace.zoom.us** に自分のZoomアカウントでログイン
2. 右上「Develop」→「Build App」→ **「Server to Server OAuth App」** を選んで作成（名前は「個別相談予約」など）
3. 「App Credentials」に表示される **Account ID / Client ID / Client Secret** を控える
4. 「Information」で会社名・氏名・メールアドレスを入力
5. 「Scopes」→「Add Scopes」で **Meeting** の中の次の2つにチェック
   - `meeting:write:meeting:admin`（会議の作成）
   - `meeting:delete:meeting:admin`（テスト会議・失敗時の削除）
6. 「Activation」→ **「Activate your app」**
7. Apps Script に戻り、左の歯車（プロジェクトの設定）→ 一番下「スクリプト プロパティ」→「スクリプト プロパティを追加」で、次の3つを登録

   | プロパティ | 値 |
   |---|---|
   | `ZOOM_ACCOUNT_ID` | 3で控えた Account ID |
   | `ZOOM_CLIENT_ID` | 3で控えた Client ID |
   | `ZOOM_CLIENT_SECRET` | 3で控えた Client Secret |

8. エディタで関数 **`testZoom`** を選んで「実行」（追加の権限を求められたら許可）
   → ログに「Zoom連携OK」と参加URLが出れば完了（テスト会議は自動で削除されます）
9. 「デプロイを管理」から新しいバージョンでデプロイし直す

**うまくいかない時**
- `Zoom認証エラー(400/401)` → ID・Secretの貼り間違い、またはアプリをActivateしていない
- `Zoom会議の作成に失敗(400/404)` → スクリプト プロパティに `ZOOM_USER_ID` を追加し、値に自分のZoomのメールアドレスを入れる
- Zoomを一時的に止めたい → `CONFIG` の `ZOOM_ENABLED: false`（確認メールは「URLは前日までにご連絡」の文面に戻ります）

> Client Secret はパスワードと同じ扱いです。コードやLINEには貼らず、スクリプト プロパティにだけ保存してください。

> コードを書き換えたあとは「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新しいバージョン」→「デプロイ」で反映されます（URLは変わりません）。

## よくある設定変更

```js
// 仕事用カレンダーや家族カレンダーの予定も空き判定に入れたい
// （カレンダーの設定 →「カレンダーの統合」にある カレンダーID を追加）
CHECK_CALENDAR_IDS: ['primary', 'xxxxxxxx@group.calendar.google.com'],

// 木曜日は19:00と20:30をなしにしたい
EXCLUDED_SLOTS_BY_WEEKDAY: {
  2: ['10:30'],
  4: ['19:00', '20:30'],
},

// 年末年始を休みにしたい
CLOSED_DATES: ['2026-12-30', '2026-12-31', '2027-01-01'],

// 対面もWeb予約で受けたくなったら（予約画面に選択欄が出る）
METHODS: ['オンライン', '対面'],

// 前日の夜まで受け付けたい（12時間前まで）
MIN_HOURS_BEFORE: 12,

// 訪問相談があるので前後30分空けたい
BUFFER_MINUTES: 30,
```

## 運用のコツ

- **対面の相談は、自分でカレンダーに予定を入れる**だけでOK。その時間はWeb予約に出なくなります
- 対面の前後に移動時間があるなら、移動時間も予定として入れておくと安心です
- **予約を止めたい日・時間もカレンダーに予定を入れるだけ**でOK（「ブロック」などの仮予定でも可）
- 終日予定の「休み」を入れれば、その日は丸ごと予約不可になります
- 招待を「不参加」にした予定は、空きとして扱います
- Zoomは「待機室あり」で作成されます。お客様が入室したら、自分が許可して開始してください
- Zoomの会議は自分のZoomアカウントの「ミーティング」一覧にも入ります
- 予約をキャンセルするときは、カレンダーの予定に加えてZoomの会議も削除してください
- 予約の変更・キャンセルは、お客様が確認メールに返信 → カレンダーの予定を手動で移動・削除してください
