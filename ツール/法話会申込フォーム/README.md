# 法話会 申込フォーム

「松島 法話の夜」（2027年1月28日）の参加申込を受け付ける**Googleフォーム**を、Google Apps Script（GAS）で自動作成します。費用はかかりません。

## できること

- `setup` を1回実行するだけで、**質問入りのGoogleフォーム**と**回答一覧のスプレッドシート**ができる
- 申込が入るたびに参加人数を合計し、**残席に合わせて「参加人数」の選択肢を自動で絞る**（残り3名なら「1〜3名」だけ表示）
- **定員80名に達したら自動で受付終了**
- **申込締切（2027年1月25日 23:59）で自動で受付終了**し、最終人数をメールでお知らせ
- 申込者がメールアドレスを入力した場合は、**受付確認メール**（日時・会場・参加費・持ち物の案内）を自動送信
- 自分には申込ごとに**通知メール**（申込内容と、合計人数・残席）

## セットアップ手順（10分ほど）

1. **https://script.google.com** を開き、「新しいプロジェクト」を作成。名前は「法話会申込フォーム」など
2. 最初からある `コード.gs` の中身をすべて消して、`Code.gs` の内容を貼る
   （`appsscript.json` の貼り付けは任意。貼らなくても必要な権限は自動で求められます）
3. タイムゾーンが「(GMT+09:00) 日本標準時」になっているか、左の歯車（プロジェクトの設定）で確認
4. 保存して、上部の関数選択で **`setup`** を選び「実行」→ 権限の許可画面で自分のアカウントを選んで許可
   （「このアプリは確認されていません」と出たら「詳細」→「◯◯（安全ではないページ）に移動」）
5. 実行ログに3つのURLが出ます
   - **申込フォーム（お客様用）**：`https://forms.gle/…` の短いURL。チラシのQRコード、LINE、SNSに使う
   - **フォームの編集画面**：デザインや文言を手で直したいとき
   - **回答スプレッドシート**：申込一覧（受付名簿のもと）
6. 自分で**テスト申込**を1件送り、確認メールと通知メールが届くか確認
7. テスト申込を削除：フォームの編集画面 →「回答」タブ →「個別」→ ゴミ箱マーク
   （**スプレッドシートの行を消すだけでは人数から外れません**。必ずフォーム側で削除してください）
8. テスト申込を消したら、関数 **`showStatus`** を実行して「参加人数の合計：0名」になっていればOK

## チラシ用のQRコードを作る

- **Chrome**：フォームの短いURLを開く → アドレスバー右の共有アイコン →「QRコードを作成」→ ダウンロード
- できたQR画像をチラシの「申込用QRコード」の枠に差し込みます

## 運用中に使う関数

| 関数 | 使うとき |
|---|---|
| `showStatus` | 今の申込件数・合計人数・残席を確認したい（実行ログに表示） |
| `reopenForm` | キャンセルの連絡があり、フォームの「回答」タブでその回答を削除したあと。人数を数え直して受付を再開 |
| `updateDeadline` | 申込締切を変更したい（下の注意点を参照） |
| `resetSetup` | フォームを作り直したい（自動処理を止める。古いフォームはドライブから手動で削除） |

## 注意点

- **キャンセルや人数変更**は電話で受け、フォームの「回答」タブで該当の回答を削除 → 人数変更なら代わりに自分で申込し直す → `reopenForm` を実行
- 同時に申込が重なると、まれに定員を少し超えることがあります。その場合は通知メールに「定員を◯名超えています」と出るので、個別にご連絡ください
- 確認メールは**自分のGmailアドレスから送信**されます（送信者名は「小野 健汰」）。1日の送信上限は無料アカウントで100通程度なので、80名規模なら問題ありません
- 電話でのお申込みは、自分でフォームに代理入力すると人数管理が一本化できます
- 日時・会場・定員・締切などは `Code.gs` 冒頭の `CONFIG` で変更できます。**`setup` を実行する前に**直してください（実行後に変えた場合、フォームの説明文はフォームの編集画面で手直しが必要です）
- 申込締切を延ばしたいとき：`CONFIG` の `DEADLINE` と `DEADLINE_TEXT` を変更 → 関数 `updateDeadline` を実行 → フォームの説明文の締切日を編集画面で直す
