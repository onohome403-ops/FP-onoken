# デザインルール：Threads 投稿画像

> Threads に載せる画像を、毎回同じ見た目・同じ手順で作るための決まりです。
> Canva でテンプレートを作るときと、Claude に画像の原稿を頼むときの両方で使います。
> 表現のルールは [インスタグラム運用計画.md](インスタグラム運用計画.md) の9章「守ること」とそろえています。

---

## 0. 結論（6つの決定事項）

| 項目 | 決定 |
|---|---|
| 用途 | Threads の投稿画像（4:5 なのでインスタにも流用できる） |
| 読者 | 親の介護が気になり始めた **30〜50代の子ども世代** |
| 雰囲気 | **親しみ・身近**：地域の相談役。宮城のローカル感と人柄が伝わる |
| 文字 | **丸ゴシック**。1枚目は「ひとこと型」、2枚目以降は「要点3つ型」 |
| 絵 | **イラストのみ**（顔出しなし） |
| 名前 | **毎回右下に小さく入れ、最後の1枚に案内をまとめる** |
| 表現 | NG表現のルール＋**投稿前チェックリスト**（7章） |

---

## 1. サイズと枚数

- **サイズ：** 1080×1350px（縦 4:5）。タイムラインで大きく表示される。
- **枚数：** 基本は **3〜5枚**。文章が主役のSNSなので、画像は「指を止める」「保存させる」役に絞る。
- **余白：** 上下左右に **80px 以上**の余白を取る。この範囲には文字を置かない（スマホ表示で切れないようにするため）。

---

## 2. 色

| 役割 | 色 | コード | 用途 |
|---|---|---|---|
| 背景 | ウォームホワイト | `#FFF9F2` | すべての画像の下地 |
| メイン | テラコッタ | `#D9774B` | タイトル帯、アクセント線、アイコン |
| 文字 | こげ茶 | `#3E2C23` | 見出し・本文・右下の表記 |
| 数字の強調 | 濃いオレンジ | `#C8551E` | 金額・日数・割合など、保存したくなる数字だけに使う |
| 補助 | ベージュ | `#F3E3D3` | 表や囲みの下地 |

**守ること**
- 使う色は**上の5色だけ**。新しい色は足さない。
- **赤・黒・蛍光色は使わない**（警告のように見えて不安をあおるため）。
- 濃いオレンジは **1枚に1か所まで**（使いすぎると強調にならないため）。

---

## 3. 文字

| 項目 | ルール |
|---|---|
| フォント | **M PLUS Rounded 1c**（Canva で利用可）。これ以外は使わない |
| 見出し | 太字・72〜96pt目安・**1行12文字まで、2行まで** |
| 数字 | **見出しの1.5倍以上**・濃いオレンジ・太字 |
| 本文 | 標準の太さ・40〜48pt目安・**1行15文字前後、1枚5行まで** |
| 出典・注記 | 24pt目安・こげ茶・画像の下のほうに置く |
| 行間 | 1.4〜1.6 |

**書き方**
- 漢字を続けすぎない。ひらがなを多めにする（例：「申請手続」→「申請のしかた」）。
- 専門用語にはひとことで説明を添える（例：「負担限度額認定（食費・部屋代が安くなる制度）」）。
- 金額には必ず「目安」と「〇年時点」を入れる。

---

## 4. 画像の型（何枚目に何を置くか）

### 1枚目：ひとこと型（指を止める）
```
┌────────────────────┐
│ ［テラコッタの帯］テーマ名      │
│                                  │
│   親が施設に入ったら              │  ← 見出し（問いかけ）
│   月 15万円                       │  ← 数字（特大・濃いオレンジ）
│   かかることも                     │
│                                  │
│          （イラスト1点）           │
│ ※宮城郡の目安・〇年時点            │
│        @アカウント｜宮城の介護とお金 │ ← 右下に小さく
└────────────────────┘
```
- 伝えることは **1つだけ**。余白を広く取る。
- 数字は投稿の内容に合わせて差し替える（上の金額はレイアウトの例）。

### 2枚目以降：要点3つ型（保存させる）
```
┌────────────────────┐
│ 小見出し（例：知っておきたい制度）│
│ ─────────（テラコッタの線）     │
│ ① ○○○○○○○○○              │
│ ② ○○○○○○○○○              │
│ ③ ○○○○○○○○○              │
│ ［ベージュの囲み］ひとことメモ     │
│        @アカウント｜宮城の介護とお金 │
└────────────────────┘
```
- 箇条書きは **3つまで**。4つ以上になるときは2枚に分ける。
- 番号は丸数字（①②③）に統一する。

### 最後の1枚：案内（行動につなげる）
- 「保存して、あとで見返してください」の一言。
- プロフィール：「元看護師・ケアマネのFP｜宮城の介護とお金」
- LINE案内：「宮城の介護費用 早見表を無料でお渡ししています（プロフィールのリンクから）」
- 右下の表記はこの1枚にも入れる。

---

## 5. イラスト

- **イラストのみ使う。** 写真と顔出しはしない。
- タッチ：**線が少なく、やさしい手描き風**。色はテラコッタ・ベージュ・こげ茶に近いものを選ぶ（Canva では色を変更できる素材を優先する）。
- **1枚に1点まで**。文字より目立たせない（画像の面積の3分の1以内）。
- Canva での検索語の例：「家族 シンプル」「親子 線画」「家 イラスト」「手 つなぐ」「電卓」「カレンダー」。
- 使わないもの：病院・ベッド・車いすを強調した絵、泣き顔、お札の山（不安やお金の生々しさが前に出るため）。

---

## 6. 名前・アカウント表記

- **全画像の右下**に「@アカウント名｜宮城の介護とお金」を入れる（こげ茶・24pt目安）。画像だけが保存・転載されても、発信者がわかるようにするため。
- **最後の1枚**に、プロフィールとLINE案内をまとめる（4章）。
- 会社名・電話番号・住所は画像に入れない。

---

## 7. 表現のルールと投稿前チェックリスト

### 使わない表現
| NG | 言いかえ |
|---|---|
| 必ず・絶対・確実に | 〜のことが多い・〜の場合がある |
| 損しない・得する・儲かる | 備えておくと安心・知っておくと役立つ |
| おすすめの保険／特定の商品名・会社名 | （出さない。相談につなげる） |
| 今すぐ入らないと手遅れ | 早めに考えておくと選べる手段が増える |
| 〇〇の病気なら□□すべき（医療判断） | 気になる場合は主治医・地域包括支援センターへ |

### 投稿前チェックリスト（毎回すべてにチェック）
- [ ] 所属会社・代理店のSNS規程を確認し、必要な審査・承認を得た
- [ ] 特定の保険・金融商品の名前・比較・利回り・「おすすめ」が入っていない
- [ ] 断定表現（必ず・絶対・損しない など）が入っていない
- [ ] 金額・割合に **出典と時点** を入れ、「目安」と明記した
- [ ] 事例は匿名にし、個人が特定されないよう内容を変えた
- [ ] 医療・法律の個別の判断になっていない（専門家・窓口へ案内している）
- [ ] 色は5色のみ、赤・黒・蛍光色を使っていない
- [ ] フォントは M PLUS Rounded 1c のみ
- [ ] 見出しは12文字×2行以内、本文は1枚5行以内
- [ ] 全画像の右下にアカウント表記がある
- [ ] 最後の1枚に保存の呼びかけとLINE案内がある
- [ ] スマホで実際に表示して、文字が読める・切れていない

---

## 8. Canva での作り方（最初の1回だけ）

1. 「カスタムサイズ 1080×1350px」で新しいデザインを作る。
2. ブランドキット（またはデザイン内のカラー）に2章の5色を登録する。
3. 4章の3つの型（1枚目・2枚目以降・最後の1枚）を作り、**テンプレートとして保存**する。
4. 右下のアカウント表記は、3つの型すべてに先に入れておく。
5. 以後は**テンプレートを複製して文字とイラストを差し替えるだけ**にする。

---

## 9. Claude に画像の原稿を頼むときの指示文（コピーして使う）

```
「ノウハウ/デザインルール_Threads.md」のルールに沿って、
Threads の投稿画像の原稿を作ってください。

テーマ：〔例：負担限度額認定で施設の食費・部屋代が安くなる話〕
枚数：〔3〜5枚〕

出してほしいもの：
・1枚目（ひとこと型）：見出し（12文字×2行以内）＋強調する数字1つ＋出典・時点
・2枚目以降（要点3つ型）：小見出し＋箇条書き3つ（各15文字前後）
・最後の1枚：保存の呼びかけ＋LINE案内
・各枚に合うイラストの Canva 検索語
・Threads の本文（500文字以内）
・7章のチェックリストでの自己確認結果
```
