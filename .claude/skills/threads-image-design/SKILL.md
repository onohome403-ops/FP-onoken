# Threads 投稿画像のデザインスキル

親の介護が気になり始めた **30〜50代の子ども世代** に向けて、宮城の介護とお金をやさしく伝える Threads 投稿画像を作ります。
雰囲気は **「親しみ・身近」**（地域の相談役）です。毎回同じ見た目にすることで、タイムラインで「この人の投稿だ」と気づいてもらい、保存してもらうことがねらいです。

細かい数値（文字サイズ、レイアウト図、Canva の初期設定、言いかえ表の全体）は `references/design-rules.md` にあります。原稿を作る前に一度読んでください。

## なぜこの決まりなのか（判断に迷ったときの軸）

- **Threads は文章が主役。** 画像は「指を止める1枚目」と「保存したくなる2枚目以降」の役に絞る。だから枚数は3〜5枚、1枚に伝えることは1つ。
- **読者は不安を抱えている。** 赤・黒・蛍光色、病院やベッドを強調した絵、断定や脅しの言葉は、読む前に離れさせる。あたたかい色とやさしい言葉で、数字だけははっきり見せる。
- **保険・金融の発信には規程がある。** 商品名や断定表現が入ると審査で差し戻され、信頼も失う。チェックは毎回する。

## コアルール（要約）

| 項目 | ルール |
|---|---|
| サイズ | 1080×1350px（4:5）、3〜5枚、上下左右80px以上の余白 |
| 色 | 背景 `#FFF9F2` ／メイン テラコッタ `#D9774B` ／文字 こげ茶 `#3E2C23` ／数字 濃いオレンジ `#C8551E`（1枚に1か所まで）／補助 ベージュ `#F3E3D3`。この5色だけ |
| フォント | M PLUS Rounded 1c のみ。見出しは太字・12文字×2行以内、本文は1行15文字前後・1枚5行以内、数字は見出しの1.5倍以上 |
| 1枚目 | ひとこと型：問いかけの見出し＋数字1つ＋出典・時点。余白を広く |
| 2枚目以降 | 要点3つ型：小見出し＋①②③の箇条書き（4つ以上なら分ける） |
| 最後の1枚 | 「保存して、あとで見返してください」＋プロフィール＋LINE案内（宮城の介護費用 早見表） |
| 絵 | やさしい線のイラストを1枚に1点まで。写真・顔出しなし |
| 表記 | 全画像の右下に「@アカウント名｜宮城の介護とお金」。会社名・電話番号・住所は入れない |

## 進め方

1. **テーマと数字の根拠を確かめる。** テーマ・伝えたい結論・使う数字を確認する。数字はリポジトリ内の `ノウハウ/介護費用試算_宮城郡.md` などの根拠を優先し、出典と時点がわからない数字は作らずにユーザーに確認する（作った数字は審査で通らず、読者を誤らせるため）。
2. **枚数と流れを決める。** 1枚目で問い → 2枚目以降で答えと要点 → 最後に案内、の流れで3〜5枚に割り振る。
3. **原稿を作る。** 下の出力形式で書く。文字数の上限を守り、漢字の連続を避けてひらがなを多めにし、専門用語にはひとことの説明を添える。
4. **セルフチェックする。** `references/design-rules.md` の7章チェックリストで確認し、結果を出力に含める。審査・承認など本人しか確認できない項目は「要確認」とする。
5. **Canva で作る場合。** Canva のツールが使えて、ユーザーが望むなら、保存済みテンプレートを探して流し込む。テンプレートがなければ、8章の手順で3つの型を先に作ることを提案する。

## 出力形式

次の形で出力する。

```
## 投稿テーマ：〔テーマ〕

### 1枚目（ひとこと型）
- 見出し：〔12文字以内〕／〔12文字以内〕
- 強調する数字：〔数字＋単位〕
- 出典・時点：〔例：宮城郡の目安・2026年時点〕
- イラスト（Canva検索語）：〔例：親子 線画〕

### 2枚目（要点3つ型）
- 小見出し：〔…〕
- ① 〔15文字前後〕
- ② 〔15文字前後〕
- ③ 〔15文字前後〕
- ひとことメモ（ベージュの囲み・任意）：〔…〕
- イラスト（Canva検索語）：〔…〕

（3枚目以降も同じ形）

### 最後の1枚（案内）
- 保存して、あとで見返してください
- 元看護師・ケアマネのFP｜宮城の介護とお金
- 宮城の介護費用 早見表を無料でお渡ししています（プロフィールのリンクから）

### Threads 本文（500文字以内）
〔問いかけ → 結論 → 現場での気づき → 保存・LINEへの案内〕

### チェック結果
〔チェックリスト各項目：OK／要確認（理由）〕
```

## 言葉のルール（よく使う言いかえ）

- 「必ず・絶対」→「〜のことが多い・〜の場合がある」
- 「損しない・得する」→「知っておくと役立つ・備えておくと安心」
- 「今すぐ入らないと手遅れ」→「早めに考えておくと選べる手段が増える」
- 特定の保険・金融商品名、会社名、利回り、「おすすめ」は出さず、相談につなげる。
- 医療・法律の個別判断はせず、主治医・地域包括支援センターなどの窓口へ案内する。
- 現場のエピソードは匿名にし、個人が特定されないよう内容を変える。
