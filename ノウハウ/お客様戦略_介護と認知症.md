# お客様戦略：介護・認知症とお金

> これまでのノウハウ（介護費用セミナー、宮城郡の試算、認知症講座）と、既存の勉強会資料（ケアマネ向け・施設向け・NPO向け提案書）をまとめて設計した戦略です。

---

## 0. 結論

**「医療・介護の現場を知るFP」として、介護と認知症のお金の相談窓口になる。**
次の3つの入口を、**個人 → 法人 → 行政** の順に積み上げていく。

| 入口 | 対象 | 最初の一手 |
|---|---|---|
| ① 既契約者・知人 | シニア世代、子ども世代、独身者・DINKS | 公式LINEでオンラインセミナーに案内 |
| ② 介護の専門職 | ケアマネ、施設、NPO | 無料の出張勉強会（資料は作成済み） |
| ③ 法人・行政 | 既契約法人、地元企業、町・地域包括 | 介護離職防止勉強会、実績を持って講座を提案 |

- お客様の悩みは「**介護費用（高さ×長さ）**」と「**認知症による資産凍結**」の2つ。
- 自分の役割は、制度・保険・専門家を整理して組み合わせ、**家族の間に入る**こと。

---

## 1. 自分の強み（ポジショニング）

- 看護師・保健師・ケアマネとしての現場経験。病状や介護度の変化を、保険の支払条件とつなげて確認できる。
- 生保・損保・IFAのすべてを扱える。保険・資産運用・資産凍結対策を一か所で相談できる。
- 相続診断士。相続・家族信託の論点を整理して、士業へ正確につなげる。
- **差別化のメッセージ：**「介護が始まる前に、お金と手続きの段取りを一緒に決める人」

---

## 2. ターゲット別の戦略

| ターゲット | 主な悩み | 入口のテーマ | 提供する解決策 | 次につながるもの |
|---|---|---|---|---|
| **シニア世代の既契約者**（50〜70代） | 介護費用は足りる？認知症になったら？ | 「わが家の介護費用と資産凍結チェック」 | 不足額の試算、保険の棚卸し（指定代理請求・受取人・介護特約）、家族信託・任意後見の整理 | 子ども世代の紹介、資産運用の相談 |
| **子ども世代の既契約者**（30〜40代） | 親の介護が心配、仕事を続けられる？ | 「親の介護とお金」セミナー | 親の施設費用の試算、介護休業・公的制度、自分の就業不能への備え | **親世代の紹介**（いちばん強い起点） |
| **独身者・DINKS**（40代以上） | 頼れる家族がいない | 「おひとりさまの介護と死後の手続き」 | 自分の介護費用（松竹梅）、身元保証・死後事務の紹介、任意後見 | 保険・資産形成の相談 |
| **社長・開業医** | 本人の認知症で会社や医院の資産が動かなくなる | 「経営者の認知症リスク」 | 法人保険、家族信託・後見の整理、士業の紹介 | 法人の勉強会、従業員の相談 |
| **既契約法人・地元企業** | エース社員の介護離職 | **介護離職防止勉強会** | 社員向け勉強会、個別相談（希望者のみ） | 福利厚生の提案、従業員の個人相談 |
| **ケアマネ・施設・NPO** | 利用者家族のお金の相談に手が回らない | 出張勉強会（作成済み資料を活用） | 眠っている保険の確認、費用試算、制度の申請 | 利用者家族からの相談（紹介料の授受なし） |
| **士業** | 保険・お金の相談先がほしい | 相互紹介の勉強会 | 保険の受取人設計・代理請求の知識を提供 | 相互紹介のパートナー |
| **公務員・行政** | 地域の認知症・介護の啓発 | 町・地域包括・社協での講座 | 介護費用・資産凍結の講座 | **包括協定**（中長期） |

---

## 3. 既契約者のABC分けとアプローチ

| ランク | 定義（目安） | アプローチ |
|---|---|---|
| **A** | 関係が深い。家族構成や資産状況を把握している | 個別面談で「介護費用・資産凍結チェック」を直接提案 |
| **B** | 定期的に連絡を取っている | オンラインセミナーに個別のメッセージで誘う |
| **C** | 契約後あまり接点がない | 公式LINE・年賀状などで繰り返しセミナーを案内する（フック） |

- まず30分で **リストアップのワーク** をする。項目：既契約法人／知り合いの社長／大手企業のエース社員／40歳以上の独身者／DINKS／開業医／士業／公務員／子ども世代の既契約者／地域活動・PTA・ジュニアスポーツのつながり。
- リストの各人にABCとターゲットの型を付ける。そのまま **顧客棚卸しシート** になる。

## 4. 集客から成約・紹介までの導線

```
公式LINE・個別メッセージで案内（フック）
　↓
オンラインセミナー（45〜60分）
　「宮城の介護費用、いくら？」…参加者が自分の地域をその場で検索
　↓
個別相談（希望者のみ）
　・不足額の試算（高さ×長さ。期間は2パターン）
　・資産凍結チェック（預金・NISA・不動産・保険）
　・保険の棚卸し（指定代理請求・受取人・介護特約）
　↓
解決策の提案
　・保険：介護・認知症保険、終身保険、受取人と代理人の設計
　・保険以外：家族信託、任意後見、銀行の代理人サービス、証券会社の家族サポート
　・専門家の紹介：司法書士・行政書士・税理士・身元保証・生前整理
　↓
フォローと紹介（子ども世代 → 親世代、社長 → 社長）
```

### 試算の型（セミナーと個別相談で共通）
- **高さ**：地域の施設月額（みんなの介護の中央値）＋介護保険の自己負担＋雑費
- **長さ**：A＝平均介護期間 55か月／B＝健康寿命と平均寿命の差（男性 約8.5年・女性 約11.6年）
- **備える額**：（月額計 − 年金から充当できる額）× 期間 ＋ 一時金
- 宮城郡の例（55か月）：在宅 約333万円／梅 約545万円／竹 約902万〜1,131万円／松 約1,360万円

## 5. 人脈マップ（宮城でそろえる紹介先）

| 相談 | 紹介先 | 現状 |
|---|---|---|
| 家族信託・後見・遺言 | 司法書士・行政書士 | □ |
| 相続税・不動産の評価 | 税理士 | □ |
| 身元保証・死後事務 | 民間の身元保証サービス | □ |
| 家財整理・施設に持ち込めない物の売却 | 生前整理・買取業者 | □ |
| 自宅の売却・活用 | 不動産会社 | □ |
| 介護サービス・施設探し | ケアマネ、地域包括、施設紹介 | ○（既存の関係あり） |
| 地域の相談窓口 | 社会福祉協議会（日常生活自立支援事業） | □ |
| 口座の手続き | 地元の主要銀行の代理人サービス（対応状況を調べる） | □ |

→ 各分野で **最低1人ずつ** つながっておく。互いに紹介しあえる関係にすることを目指す。

## 6. 90日アクションプラン

### 1か月目：準備
- [ ] リストアップのワーク（30分）とABC分け
- [ ] 公式LINEの準備、セミナー案内文のテンプレート作成
- [ ] 人脈マップのうち3分野（司法書士・身元保証・生前整理）で面談
- [ ] 宮城県・郡内の町で、介護離職防止や認知症啓発の補助制度・財団事業を調べる
- [ ] 地元の主要銀行の代理人サービスの対応状況を調べる

### 2か月目：小さく始める
- [ ] 既契約者向けオンラインセミナーを1回開く（目標：約100人に声をかけ、10〜20人参加）
- [ ] ケアマネ事業所・施設で出張勉強会を2件
- [ ] 既契約法人1社に介護離職防止勉強会を提案

### 3か月目：個別相談と事例化
- [ ] セミナー参加者の個別相談（試算・資産凍結チェック・保険の棚卸し）
- [ ] 勉強会の **実施報告書** と、相談事例（匿名化）を蓄積
- [ ] 2回目のセミナー（子ども世代向け「親の介護とお金」）

### 6〜12か月：行政へ
- [ ] 法人の勉強会を複数社で実施し、実績データをまとめる
- [ ] 郡内の町（松島町・七ヶ浜町・利府町）の地域包括・社協に講座を提案
- [ ] 実績をもとに、自治体との連携（包括協定など）を打診

## 7. 追いかける数字（KPI）

| 段階 | 指標 | 目標の目安 |
|---|---|---|
| 集客 | 声かけ数 → セミナー参加数 | 100人 → 10〜20人 |
| 相談 | セミナー参加 → 個別相談 | 参加者の3割程度（仮置き） |
| 専門職ルート | 勉強会の実施件数 | 月2件 |
| 紹介 | 紹介元（子ども世代・ケアマネ・士業）ごとの件数 | 毎月記録する |
| 人脈 | 紹介先の分野数 | 8分野中6分野以上 |

※相談率などの目標は仮置きです。1回目の実績で見直す。

---

## 8. 守ること（信頼の土台）

- 勉強会の場では商品を案内しない。個別相談は本人の希望があるときだけ（既存資料の約束どおり）。
- ケアマネ・施設からの紹介で、謝礼・紹介料は授受しない（公正中立への配慮）。
- 保険の募集では、意向を把握して比較説明をする。高齢の方には家族の同席など、高齢者対応のルールを守る。
- 法律判断や登記・書類作成は士業へ。自分は論点の整理と橋渡しに徹する。
- 個人情報は本人が同意した範囲でのみ扱う。
