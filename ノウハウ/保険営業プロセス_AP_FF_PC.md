# 保険営業プロセス（AP → FF → PC）

小野が実際の面談で使っている営業プロセスのベース。ロープレの文字起こし（AP台本・FF台本・PC①〜③）を整理したもの。
提案書、台本、ロープレ、セミナー構成などを作るときは、この流れと話法の型を前提にする。

> 元の台本には、ロープレ相手の名前や他社名、芸能人のエピソードが入っている。ここでは「○○さん」「ネット専業生保」のように一般化して書いている。

---

## 0. 全体像

| 回 | 名称 | 時間の目安 | 目的 | 次回へのつなぎ |
|---|---|---|---|---|
| 1回目 | **AP**（アプローチ） | 約35分 | 保険のイメージを変える（「死ななきゃもらえない」から「貯まって増える・自分がもらう」へ）。世間の保険の問題点に気づいてもらい、信頼と紹介の種をまく | 「夢のような保険を見てみたい？」→ オーダーメイドの聞き取り（70分）のアポを取る |
| 2回目 | **FF**（ファクトファインディング） | 約70分 | 「私たちの将来」シートを使い、万が一（IF）と万が万（WHEN）の必要額を一緒に出す。**入口の話**（どんな経済リスクを抱えているか） | ベストプランを持ってくる予告。誕生日はここで初めて聞く。宿題は「毎月いくら積み立てられるか」 |
| 3回目 | **PC**（プレゼンテーション＆クロージング） | 75〜80分（前半50分＝保険の5つの使い方、後半20〜25分＝商品）。目標はもっと短く | **出口の話**（100%受け取るために担当者をどう使うか＝約款の説明）→ ニーズごとに商品を分けて提示 → リスク説明 → その場で申込み | 「これから金額調整するので、その間にお手洗いへどうぞ」→ 申込み手続き |

**一貫した考え方**
- 保険の基本の種類は3つだけ（**定期・養老・終身**）。目的に合っていればどれも良い保険、合っていなければどれもダメな保険。
- **早く入るほど得**（AさんBさん）。後回しにすると100%損をする金融商品。
- 保険料は全社ほぼ横並び（同じ生命表を使い、運用先の国債金利も同じ）。だから最後の決め手は「**目の前の担当者を信頼できるか**」。
- 受取りの4パターン（死亡・入院手術・満期解約・高度障害）のうち、**3つは自分が受け取る**。
- 保険料の高い・安いは金額ではなく、**目的に合っているかどうか**で決まる。

## 1. AP（アプローチ）約35分

想定：異業種交流会で名刺交換した独身の方（25歳、会社員）との初回面談。

### 流れ
1. **事前承諾（オープニング）**
   - 「つまらない、興味がわかないと感じたら遠慮なく断ってください」「面白いと感じたら、次回は今日より少し長く時間をください」。この2つにYESをもらっておく。
2. **FPとは何か**：たくさんある金融商品で失敗しないようにアドバイスする仕事。
3. **イメージの転換**：「保険は死ななきゃもらえないイメージですよね。独身だと興味ないですよね。でも**お金が貯まって増える話**ならどうですか？」（興味がなければ3分で帰る、と言っておく）
4. **金融商品の円グラフ（株・銀行・保険）**
   - 株：値上がりすれば増え、値下がりすれば減る。元本保証のないハイリスク・ハイリターン。安定していると思われていた大企業の株でも紙くずになった例がある。
   - 銀行：安心して着実に貯まるが、今は増えない（元本を1.5倍にするのに約250年。バブル期は6〜7年）。預金金利は低いのに、グループの消費者金融は高い金利で貸している、という話。
   - 保険：金融商品で唯一「**安心**」が得られる（何か起きたら満額）。弱点は「掛け損・掛け捨て」のイメージ。
   - → 3つの良いところを合わせた「**定年までに積んだお金が1.5倍以上になり、死ぬまでずっと振り込まれ、受け取り方も選べる貯金**」があったら興味ありますか？
   - 「この話は聞く耳を持った賢い人しか得られない情報」→「賢い。周りの人は知らないので、どんどん紹介してください」（**紹介の種**）
   - 9倍10倍とうたって破綻した外資系の例 → 無理のない1.5倍がちょうど良い。
5. **AさんBさん（早いほど得）**
   - 25歳から始めるAさんと、結婚してからと10年遅らせたBさん。65歳で受け取る額は同じ。
   - 毎月の保険料が高いのは？→B。**総額が高いのは？→これもB**（8割の人が「同じ」と答え、正解できるのは5%だけ）。
   - 理由は2つ：①死亡リスク（年齢が上がると高くなる）②時間（保険会社が運用できる期間が長い）。
   - Aさんはその間の保障も得ている。Bさんは35歳で病気になって入れない可能性がある（保険は**唯一、健康状態を問われる買い物**）。
   - 「結婚してから・子どもができてから」は危険。**老後は誰にでも来る**ので、気づいたら今すぐやるべき貯金。
6. **保険は3つしかない（定期・養老・終身）**
   - 金融庁の認可商品は約2000種類あるが、基本は3種類。
   - 定期：期間限定の掛け捨て。**安い保険料で大きな保障**。
   - 養老：満期金は自分、途中で亡くなれば家族へ。**死亡保険金と満期保険金は同額**（最大の特徴）。
   - 終身：払込みを終えたら一生涯の保障。
   - 「どれが一番安心ですか？」と、わざと終身を選ばせる質問をする → 実は**目的に合えばどれも良い保険**。
   - 目的クイズ：子どもの教育費と生活費 → 定期／65歳で退職金代わりに2000万 → 養老／葬儀代と治療費の精算に500万 → 終身。
   - 終身の使い道は2つだけ（**死後の整理資金**と**相続税**）。
7. **L字型の「終身」（定期付終身・更新型）の実例**（自分の失敗談として話す）
   - 30歳で加入した「5000万終身」の中身は、終身200万＋15年定期4800万。
   - 40歳で亡くなれば5000万、45歳を1日でも過ぎると200万。
   - 更新すると保険料は倍になる（延長ではなく**同じ内容に入り直し**だから）。何も言わなければ自動更新。
   - 60歳で特約は終わる（**特約は主契約の払込期間を超えて更新できない**というルール）。
   - 払込総額は約920万、60歳での解約返戻金は約160万 → 「200万の保障を残すか、160万を受け取って無保険になるか」の究極の選択。
   - 「付き合いで入ってくれますか？」→ 入らない。
     - 既契約なし：「周りの人の9割がこれだとしたら？」
     - 既契約あり：「今入っている保険がこれだとしたら？」
   - なぜ入ってしまうのか → **説明を受けていないから**。保険そのものに罪はなく、売り方に問題がある → 業界の売り方を変えたいという会社の理念に共感して今の仕事をしている、という自己開示。
8. **紹介の考え方**
   - 「仲の良い友達が川に920万を投げ捨てていたら止めますよね」。でも保険屋が止めに行くと胡散臭く見えて聞いてもらえない。
   - →「**紹介してあげないと話を聞いてもらえない、かわいそうな人**だから紹介してあげよう」という気持ちで紹介してほしい。
9. **入口で重視すべき3つのポイント**
   1. **保障期間**：目的に合わせる（教育資金に終身はいらない。満期のない養老は使えない。がん保障が1年だけでは困る）。
   2. **保険料の払い方**：値上がりするかしないか、いくら払っていくら戻るか、何年払うか（できれば定年まで）。
   3. **保障額**：根拠のある金額になっているか（「20〜30代の独身なら2〜3千万で十分」の根拠は？親に仕送りしている独身もいれば、保険がいらない人もいる）。
   - 自分の加入時を○×△で振り返る（全部×）→ お客さまの加入時も振り返ってもらう（全部×）→「私なら3つとも○にできます」（目的に合わせた期間、ステップ払いなど納得したうえでの払い方、根拠のある金額に愛情として上乗せ、など）。
10. **次回のアポ取り**
    - 「65歳で『葬儀代だけ残してあとは老後資金に』と言われたら、1.5倍以上にしてお返しする。これを1つの保険でできるとしたら？」→ 見てみたい？
    - 「誕生日だけ聞いて設計書を持ってくると、それはパッケージ商品になってしまう」→ **オーダーメイドの聞き取り（約70分）**の時間をもらう。

## 2. FF（ファクトファインディング）約70分

ツールは「**私たちの将来**」シート。左に「万が一（IF＝起きるかもしれない資金）」、右に「万が万（WHEN＝いつか必ず起きる資金）」が各10項目ほど並ぶ。
「生命保険は○○さんの代わりにはなれない。ただ、お金の面では**ご本人**とご家族を支えられる」から入る。

### 流れ
1. **受取りの4パターン**：死亡／入院・手術／満期・解約／**高度障害** → 4つのうち3つは自分が受け取る。
2. **高度障害のイメージづくり**
   - 約款で定める高度障害（両目の失明、両腕・両足の切断や麻痺、言語・咀嚼機能の喪失）。
   - 居眠り運転の事故で両腕が動かなくなった、というストーリー → 仕事はできない、でも生きている。誰が面倒を見る？→ 親。
   - これを「**経済的死亡**」と呼ぶ。死亡保険金と同額の高度障害保険金を**本人が受け取り**、面倒を見てくれる人の生活費に回せる。
3. **リスクの大きさを数字で示す**
   - 20〜39歳（約2500万人）のうち、年間約5000人が急に働けなくなる（5000人に1人）。
   - 交通事故の死者は年間2663人（2024年）、そのうち働き盛りは約600人 → **働けなくなるリスクは事故死の8倍以上**。
   - 自動車の任意保険は99%、自賠責は100%の人が入っている（どちらも他人のため）。自分のリスクを放置していていいのか？
   - 警察庁の統計は24時間以内に亡くなった人だけを数えている。医学の進歩で、昔なら亡くなっていた人が高度障害に移っている。
4. **なりたくないランキング**：1位 高度障害、2位 入院（世帯主なら死亡が2位）、4位 満期 →「**気づきにくく、なりたくないものほど、なったときにお金がかかる**」。
5. **大切な人を確認する（家族構成のヒアリング）**
   - 大切な人の1位（独身なら親）、実家の場所、兄弟。
   - 友人・知人：**職場で一番仲の良い人の名字**を聞く（このあと例え話に何度も登場させる＝紹介の種）。
   - 0位は「自分」（ボクシングのチャンピオンは順位がつかない特別な地位、というたとえ）。
6. **死後の整理資金**
   - 葬儀代は200〜300万。現金の準備は？ 銀行口座は**亡くなると凍結される**。
   - 保険は**受取人固有の財産**なので凍結されず、すぐ払える。非課税枠もある。若いうちなら払込総額より保障額が大きい。
   - お墓：入れるお墓はあるか（自分で買うと公営で約200万〜都心なら2000万、私営は約500万）。
   - ローン（奨学金、車など）：月額×残り期間を聞く → 亡くなると負債として相続され、原則一括返済。連帯保証人の話。住宅ローンは団信でゼロになる。
   - **遺書の朗読**（墜落する飛行機の中で書かれた遺書）
     → 突然亡くなると言葉は残せない／遺書にはお金のことが一言も書かれていない＝最後に気づくのは「大切な人の存在」。
     → 「お金で愛情は買えない。でも**保険証券の保障額に愛情を込めることはできる**。私の仕事は、その愛情を込めるお手伝いをすること」。
     → メッセージカードで、どんな気持ちで入ったか、どう使ってほしいかを残せる仕組み。
     → 「昨日みんなで食事をしたのが最後」＝人間の余命はせいぜい1日。人生は理不尽（若くして急死した著名人の例）。
     → 自分では受け取れない＝**他者への愛情でしか買わない唯一の金融商品**。受取人の変更は無料（公正証書遺言は作成や書き換えに手数料がかかる）。
7. **相続対策資金**（該当する場合だけ）、**緊急予備資金**（貯金でまかなう）。
8. **長期療養資金**（医療保険はいらない、という論理）
   - 盲腸で2週間入院しても実費は5〜10万。海外（アメリカ）なら同じ盲腸で約188万、救急車も有料 → 海外旅行保険は**疾病特約**をつけて入る（プロっぽく聞こえる豆知識）。
   - 死因は4パターン（病死91%・事故3%・老衰2%・自殺4%）→ 病名のトップは？→ がん → **身内のがん経験と、かかった費用を聞く**。
   - がん保険大手のパンフレットにある「月100万×6か月」論法（激しい痛み → 個室 → 未承認の抗がん剤）への反論：
     - 個室を使うがん患者は7〜8%だけ。腹腔鏡手術が主流になり、健診による早期発見・早期治療が多数派。
     - 3割負担 → **高額療養費制度** → 健保によっては**付加給付** → 働けない間は**傷病手当金**（月収の約2/3、最長1年6か月。上乗せ給付がある健保もある）。
   - **病気への備えの優先順位**：①現金300万（半年戦えば、治るか亡くなるか）②公的制度を使い切る ③かかりつけ医を持つ ④食生活に気を配る ⑤それでも不安なら民間の医療保険。
   - 長期の療養は自宅療養になる → 入院日額は出ない → **備えるべきは死亡保障**（リビングニーズ特約で生前に受け取れる）。
   - 「押し付けません。いらないものはいらないとはっきり言います」→ 紹介につなげる。
   - 100%起きる「死」のほうが大事。でも死の話はモヤっとしていて、医療保険のCMのほうに流されがち。
9. **老後生活資金**
   - 毎日が日曜日、何をしたい？（ゴルフ・旅行・グルメ・買い物・孫）→ それには時間と健康とお金がいる。
   - 生活費は月40万（一度上がった生活水準は下がらない、インフレもある）×12か月×20年＝**9600万**。
   - 公的年金：国民年金6.8万＋厚生年金約10万（平均年収600万が条件、上限あり）。退職金（中退共で約1000万＝月4.1万の足し）。少子高齢化で支え手が半分に → **約12.5万で見ておく**。
   - 資産のヒアリング：株、投資信託・NISA、国債、FX、暗号資産、絵画、現預金、財形などの天引き。
   - 逆算：準備できている分（約3060万）を引くと不足は約6500万 ÷40年÷12か月＝**月13.6万** → 1.5倍に増えれば**月9万** → 共働きなら半分の**4.5万**（共働きと家事分担の話、専業主婦は厚生年金がもらえず損、という話）。
   - **貯まる人の仕組み**：収入−貯金（天引き）＝支出。天引き先は引き出しやすい銀行ではなく、解約しないと引き出せない**保険**。
   - 保険の貯金は**四角形**（途中で働けなくなっても満額＝リスクに強い）、銀行の貯金は**三角形**（積んだ分しか返ってこない）。
   - 80歳で預貯金がゼロになったら？（孤独死のニュース、仲の良い友人が訪ねてきて見つける、という想像）→ **終身年金**。
   - 最大の売りは「増える」ことではなく「**ずっともらえる**」こと（死ぬまで振り込まれる金融商品は生命保険会社の終身年金だけ）。**長生きは経済リスク**。
   - 定年前に亡くなる人は男性7%（女性3%）、93%は定年後も生きる → 7%には定期（掛け捨て）、93%には**養老（年金で受け取る）**で備える。
   - 保険料の高い・安いは目的で決まる（月10万でも、9万が積立なら賢い。9万が掛け捨てなら確率的に逆）。
   - 通貨の分散：国の借金と国民の金融資産、国債の外国人保有率の低さ、インフレ誘導、**マクロ経済スライド**（年金が物価に連動しない）→ 円だけでは危ない → 世界で流通しているお金の約65%を占める**米ドル**で。
   - すでにある貯金（例：1000万）の**移し替え**（250万×4年など）→ 詳しくは次回。
10. **万が一の生活資金（高度障害）**
    - 20代前半で高度障害になった方の実話（手記）を読んでもらう。
    - 損害保険は相手との交渉や裁判で何年もかかることがある。生命保険は**状態に対して支払われ**、委任状があれば請求を代行できる。
    - 付きっきりで介護する母親は働けない → 2人分の生活費（20万×2人＝月40万）×12か月×40年＝**約1億9200万**。
    - 必要額は年々減っていく（**逓減**。40歳で高度障害になったら残り25年分で1.2億）→ 巷の更新型（四角形の繰り返し）は無駄な保障が多い。
    - 準備がなければ、親の老後資金を削ることになる → 親に任せる／兄に任せる／**自分で準備する**の3択 →「自分で」。
11. **まとめと次回予告**
    - 入口でわかった3つの経済リスク：働けなくなったとき、一度は必ず亡くなること、老後（長期療養は公的制度でかなり守られている）。
    - 次回は**出口の話**：お金を払ってもらえない保険は最悪。100%受け取るために、担当者をどう使うか＝**保険の5つの使い方**（約款の中身をコント仕立てで説明）。
    - 保険料は公定価格に近い → 決め手は担当者を信頼できるかどうか。
    - 満足してもらえたら当日お預かりする。理由：先延ばしにして脳腫瘍が見つかり、入れなくなった方の実話。「**あのとき入っておけばよかった、と後悔だけはしてほしくない**」。信頼できなければ遠慮なく断ってください。
12. **責任開始の3条件と手続きの準備**
    - 責任開始の3条件：①申込書の記入 ②初回保険料の払込み ③告知。3つがそろった日から保障が始まる。
    - 用意するもの：写真つき本人確認書類、クレジットカード（または口座振替）、**健康診断の結果**（有効期間は約1年2か月。あれば病院での審査が不要）。
    - **宿題：毎月いくら積み立てられるか**。保険料の差は積立額（＝使えるお金）で決まる。財形などの天引きを「預け先を変えるだけ」で負担を増やさずに始められる。

## 3. PC（プレゼンテーション＆クロージング）

### 前半：おさらい → ベストプラン → 保険の5つの使い方
- **おさらい**：保険は3つ、早いほど得、オーダーメイドの聞き取り、受取り4パターン、各ニーズの金額（働けないとき2億・逓減／死後の整理資金は保険で／長期療養は公的制度で／老後は月40万必要で、積立は月9万、結婚すれば4.5万）。
- **ベストプラン**：ピーク時の約2億を1つの終身保険でカバー（2億終身）。「これを使って、私をどう使えるか＝約款の中身を説明します」。

#### 使い方① 亡くなったとき
- 一括で受け取ると、3年以内に半分以上を使ってしまうというデータがある → **分割（年金形式）で受け取れる**ことを案内。残りは運用されるので総額も増える。
- 事故なら災害割増、障害特約による上乗せがある。

#### 使い方② 長生きしたとき
- 解約返戻金は払込総額をどこかで上回る（例では61歳で逆転 → それまでの保障は実質タダ）。2億を受け取る権利を1.75億で買っているようなもの。
- 65歳で全部解約するのはNG（自分の口座に入るので、亡くなると凍結される）→ **減額（一部解約）**で少しずつ取り崩し、最後に整理資金として500万ほど残す。
- コールセンターに電話すると解約請求書が送られてくるだけ（「何に使うんですか？」とは聞いてくれない）。
- 来店型ショップが廃業すると、契約は保険会社の本社預かり（担当者不在）になる。
- 担当者は自分が先に死ぬ前提で**後継者を育てて引き継ぐ**＝本当の意味で一生涯フォローする。

#### 使い方③ 障害を負ったとき
- 軽い障害（片目・片腕・片足、ペースメーカー、人工肛門、人工透析など。決して軽くない）→ **保険料払込免除**。払わなくても保障は残り、お金も貯まる（相互扶助）。
- 本人が請求できないときに備える：身内からの連絡、定期的な電話、つながらなければ近所への聞き込み。
- 高度障害 → 高度障害保険金＋災害割増＋障害特約で最大3億（自宅のバリアフリー改修や車の買い替えに）。
- 請求しないまま亡くなると、担当者が手続きしていれば受け取れたはずの1億円以上を失う。
- **請求権の時効は3年**：担当者が辞めて引き継ぎが回らず、5年たって払込免除を受けられなかった実話 → 「**売れている担当者から入る**」→ MDRT（業界上位約3.5%）。（まだ会員でないときは「イチローの小学生時代のバットにサインをもらうようなもの」）

#### 使い方④ 病気以外の理由で払えなくなったとき
- リストラの例 → **払済**（保険料の払込みをやめ、保障額を下げた終身として残す）／**延長**（同じ保障額の定期保険に切り替える。例では91歳まで2億）。
- **契約者貸付**：解約返戻金の約90%まで借りられる。無担保で信用情報に傷がつかず、金利は低め、返済の催促なし。最後は死亡保険金や解約返戻金と相殺される。
- **自動振替貸付**で契約を維持していれば、がん特約などの給付も受けられる。
- 合言葉：「**支払いがきつくなったら、担当者に相談してから決めよう**」。

#### 使い方⑤ 余命半年と言われたとき
- **リビングニーズ特約**：死亡保険金の一部（最大3000万）を生前に受け取れる。非課税で使い道は自由、特約保険料はかからない。
- 誕生の歴史（1988年にカナダで生まれ、日本には1992年に導入）。
- 医師が診断書を書き渋ることがある → 委任状で担当者が請求を代行し、医師とも交渉する。
- 実例：40代の膵臓がんの方に800万を前払い。ローン返済と旅行に使い、1年半を穏やかに過ごされた。奥さまの「医療保険は入院9日分しか出なかった。**最後に役立つのは死亡保障**」という言葉 → 息子さんの紹介につながった。
- 担当者がいない売り方（ネット・ショップ・窓販）では案内されない。大震災のときに避難所や役場調査で請求を案内した、という話。告知義務違反を防ぐのも担当者の役割。
- 保険料はどこも大差ない → 本当に大事なのは「**保険金を100%お届けする**」こと。
- 「どこにサインすれば？」となったところで「保険料はいくらなのか」へ。

### 後半：ベストプランの保険料 → ニーズ別に分解して提示 → リスク説明
1. **ベストプラン（2億終身）の保険料を見せる**（例：月52.7万）→ 払えないのは支払い能力の問題で、高いわけではない（大半が積立部分）。実際に入っている人（経営者、開業医、プロ野球選手）。「宝くじが当たったらすぐ呼んでください」。
   - 最初に本当のベストプランを見せる理由：いきなり安いプランを出すと「自分の命はそんなに安くない」となるため。約款の使い方は金額に関係なく共通。
2. **働けないとき → 収入保障型（家族収入保険）**
   - 65歳満了、逓減する掛け捨て。高度障害のときは1.5倍。
   - 年金月額を調整（例：27万×1.5＝40.5万）→ 保険料は月9000円ほど。「他人のための自動車保険にそれくらい払っているなら、自分のために払ってもいいのでは」。
   - 最初から必要な額で入っておけば、結婚や子どもが増えても追加はいらない。
   - **買増権の特約**：病気でも告知なしで保障を買い増せる権利（例：余命宣告を受けても買い増して、リビングニーズで受け取れる。ヘルニアなどの部位不担保も回避できる）。ただしあくまでおまけ。
3. **死後の整理資金 → 終身（200〜500万に減額）**
   - 終身の弱点は**インフレに弱い**こと → **変額終身**（死亡保障は最低保証あり、保険料は普通の終身より3割以上安い。解約しない保険なので解約時の元本保証はいらない）。
   - 特別勘定の配分は、長期で見て米国株中心を推奨。一度決めたら基本は放置。
   - 「変額は説明に5分余計にかかり、保険料が安くなる分、私の手数料も減る。それでも説明する」＝誠実さのアピール。
   - **ドル建て終身ver**：同じ保障で保険料は半分以下。最低3〜5万ドル程度で金額を調整。
4. **長期療養 → 公的制度で守られているので最低限でいい**
   - 1社専属の場合：終身にがん特約をつけるだけ。
   - **乗合の場合**：日額5000円・終身保障・65歳払込済・先進医療特約つき・カード払い可の医療保険（月2000円以下）。
5. **老後 → ドル建て養老（年金支払型）**
   - 65歳まで月942ドル（約13万）を積み立てる → 65歳以降は**月3000ドルの終身年金**。満期金は約1.5倍弱（満期金＝死亡保険金なので、表の死亡保険金の欄を見ればわかる）。
   - 受け取り方を選べる：一括／終身年金（10年保証、**20年確定**なら約183%）／半分ずつの併用／据え置き（定年延長に対応）／繰り上げ →「40年後の状況は誰にも読めないから、選べることが大事」。
   - **裏ワザ**：10年で払済にして65歳まで置いておくと約1.9倍（あくまで緊急避難）。払済にした後も年金で受け取れる（20年確定で約233%）。「いつでも逃げられる」安心感。
6. **リスク説明（必ず最後に）＝為替**
   - 過去の円高は1995年と2012年の70円台後半。この約30年の平均は約120円。
   - 最悪のケース（払込みは140円の円安、受取りは100円の円高）でも約1000万増える／最高のケースなら約2440万増える →「最高はない＝その裏返しの最悪もない」。為替は行ったり来たりして長期では平均化されるので**一喜一憂しない**。そもそも目的は通貨の分散。
   - 銀行の普通預金（0.2%）に40年預けても、増えるのは120〜150万ほど。
7. **クロージング**：「ドル建てで、終身年金で受け取れるのはこの生命保険しかありません。これからパソコンで金額を調整するので、その間にお手洗いへどうぞ」。

## 4. 話法の型（全フェーズ共通）

| 型 | 中身 | 例 |
|---|---|---|
| 事前承諾 | 冒頭で「断ってOK」「良ければ次回」の両方にYESをもらう | AP冒頭、FFのお預かり予告 |
| クイズ形式 | 数字や理由を質問して答えさせる → 「大正解」で認める | AさんBさん、葬儀代、交通事故の死者数 |
| 登場型 | 「そんなとき私が駆けつけて『〜できますよ』と言ったらどうですか？」→「実はそれが可能で」 | 5つの使い方すべて |
| 担当者の価値の3段論法 | 「これは○○社だけ？」→「世界中の保険会社でできる」→「ただし**知らないと使えない、担当者が案内して初めて使える**」→「ネット・銀行窓販・来店型では誰が案内しますか？」 | 5つの使い方すべて |
| 紹介の種まき | 「賢い。周りの人は知らないので、どんどん紹介してください」／FFで聞いた友人の名字を例え話に登場させる | AP・FF・PCで繰り返す |
| 二択 | 「どっちが良いですか？」で自分で選ばせる | 解約か減額か、銀行か保険か |
| 逆算を見せる | 必要額 − 準備済み → 不足 ÷ 年数 ÷ 12か月を、目の前で計算する | 老後、高度障害 |
| 実話で心を動かす | 遺書、事故、膵臓がん、透析、時効、脳腫瘍 | 各フェーズの山場 |
| 次回への期待 | 「次回は〜をお持ちします。楽しみにしていてください」 | AP→FF、FF→PC |
| 目的で判断 | 高い・安いは保険料ではなく目的に合っているかで決まる | AP・FF・PC |

## 5. 小野向けのアレンジメモ

- **乗合代理店としての立ち位置**：元の台本は外資系専属の担当者がベース。小野は乗合なので、PCは「乗合で複数社を扱えるときの説明」を基本にする。「1社しか扱えない我々」というくだりは差し替える。
- **自己紹介のエピソードを差し替える**：元台本の経歴の話（実演販売、北海道、牧場勤務など）は、小野自身の**看護師・保健師・ケアマネとしての現場経験**に置き換える。
  - 長期療養資金（公的医療制度、病院を出された後の自宅療養の現実）、高度障害（介護する家族は働けない）、がんの闘病と痛みのケアは、医療の現場を知る者として話すと説得力が段違い。
  - 介護費用の話は既存のノウハウ（[介護費用セミナー_講義ノウハウ.md](介護費用セミナー_講義ノウハウ.md)、[介護費用試算_宮城郡.md](介護費用試算_宮城郡.md)）とつなげ、FFの「万が万」の項目として組み込む。
- **地域を置き換える**：例え話の地名、葬儀やお墓の相場は宮城・仙台圏のものに置き換える。
- **MDRTのくだり**は、自分の実際の状況に合わせて言い方を調整する。

## 6. コンプライアンス上の注意（台本を使う・資料にする前のチェック）

- **他社・他業態を名指しで批判しない**：元台本には銀行、ネット専業生保、来店型ショップ、国内大手生保、がん保険大手への批判がある。誤解を招く比較や誹謗中傷は保険業法300条1項6号などに触れるおそれがある。社名は出さず、根拠のある事実の比較にとどめる。資料にするなら社内のコンプラ審査を通す。
- **外貨建て・変額保険（特定保険契約）**：金融商品取引法の規制が準用されるので、断定的な判断の提供は禁止。「最悪でも1000万増える」「最悪はない」は為替だけを切り出した試算なので、為替手数料、解約控除、市場価格調整、運用実績による変動、最低保証の範囲もあわせて説明する。適合性原則と意向把握を記録に残す。
- **「医療保険はいらない」**：個人の意見として伝えるのはいいが、**意向把握義務**（お客さまの意向と提案内容が合っているかの確認と記録）は必ず果たす。
- **既契約の見直し（L字型の批判）**：乗換えになる場合は、不利益になる点（予定利率、告知のやり直し、責任開始日、新たな免責期間など）の説明が必須。既契約の保険会社を誹謗しない。
- **実在の人物や事故の話**（芸能人、スポーツ選手、事故の遺書など）：お客さまの心情や社内の審査に配慮して使う。
- **数字は2026年時点で見直しが必要なものがある**：預金金利と「1.5倍に何年」、国債残高、通貨の流通シェア、交通事故の死者数、公的年金の額、高額療養費制度の見直しの動き、付加給付や傷病手当金の上乗せ（健保・共済ごとに違う）など。資料にするときは最新の公的データで更新する。
