# 公式LINE 発信ネタ在庫（30代の公務員・医療職・介護職／既婚）

> 右腕①の分析（[お客様戦略_介護と認知症.md](お客様戦略_介護と認知症.md)・[インスタグラム運用計画.md](インスタグラム運用計画.md)）から引用した強み：
> **看護師・保健師・ケアマネの現場経験 × 生保・損保・IFAを一か所で扱える × 「申請しないともらえない制度」に強い**

## 1. ネタ10本

### お客様の「困りごと」から始まる7本

| # | 見出し | 何を話すか |
|---|---|---|
| 1 | 「共済に入っているから、保険はもう十分？」 | 職場の共済・団体保険の給付と、自分で入っている保障の重なりを確かめる3つの手順を紹介する。 |
| 2 | 公務員の退職金と年金、自分の分はどう調べる？ | 退職手当と年金の仕組みをざっくり整理し、手元の資料（ねんきん定期便など）で自分の見込みを確かめる方法を話す。 |
| 3 | 夜勤手当込みの手取りで家計を組んでいる | 妊娠・体調・異動で夜勤を外れたときの手取りの変化を「Aさん・30代・看護師」の例で試算し、基本給ベースで家計を組む考え方を伝える。 |
| 4 | 体を使う仕事で、腰を痛めて休むことになったら | 介護職に多い腰痛を例に、労災・傷病手当金・有給の使い方など、公的な支えを確認する順番を話す。 |
| 5 | 育休・時短の数年間、家計はどう変わる？ | 「Bさん・30代・ご夫婦（共働き）」の例で、育休中・時短中の収入の変化と、先取り貯蓄の金額を一時的に調整する考え方を紹介する。 |
| 6 | 資産形成、何から手をつければいい？ | 生活防衛資金 → 目的別に口座を分ける → 長期・積立・分散、の順番を説明する（利回りの数字は出さない）。 |
| 7 | 結婚・出産のとき、保障はどこを見直す？ | 加入した頃から変わった3点（家族・住まい・収入）を挙げ、死亡保障の必要額は子どもの年齢で変わることを図で示す。 |

### 僕の「日常や失敗談」から始まる3本

| # | 見出し | 何を話すか |
|---|---|---|
| 8 | 看護師時代、自分の保険の中身を知らなかった話 | 患者さんには制度を説明していたのに、自分の保障は把握していなかった失敗から、証券で最初に見る3か所を伝える。 |
| 9 | ケアマネ時代に見た「親の介護は突然始まる」 | 個人が特定されない一般的な場面として話し、30代のうちに親と話しておく3つのこと（連絡先・通帳の場所・希望）を紹介する。 |
| 10 | ジュニアスポーツの遠征費で気づいた「見えない教育費」 | 学費以外の習い事・遠征・道具代が意外とかさむという日常の話から、教育費を「学費」と「活動費」に分けて積み立てる方法を話す。 |

## 2. お客様が反応しやすい切り口（3つ）

1. **職種名を見出しに入れる**（「公務員の」「夜勤のある方へ」）— 自分のことだと気づいてもらいやすく、開封されやすい。
2. **「確かめる手順」型にする**（3ステップ・チェック項目）— 読んだあとの行動が小さく、保存や返信につながりやすい。
3. **現場経験を入口にする**（看護・ケアマネ時代の話）— 同じ医療・介護職の読み手が共感しやすく、「この人に聞いてみよう」という信頼につながる。

> 公式LINEでは、最後に「気になった番号を1つ返信してください」のような**答えやすい問いかけ**を添えると、個別のやり取りが始まりやすくなる。

## 3. 出さない方がいいネタ

| ネタ | 理由 |
|---|---|
| 公務員の給与・年金制度の改正への賛否 | 政治的な話題になる。制度の「事実」の解説にとどめる。 |
| 共済と民間保険の優劣、特定の保険・投資商品の比較 | 他社の批判・商品比較に見える。会社の規程（商品名を出さない）にも触れやすい。 |
| 過去の運用実績から「〇年で〇倍」と示すもの | 将来の結果を断定・示唆していると受け取られる恐れがある。 |
| 実際のお客様・患者さん・利用者さんの具体的なエピソード | 医療・介護の業界は狭く、匿名にしても職場や地域で特定される恐れがある。必ず複数の事例を混ぜた一般的な形にする。 |
| 決まっていない税制・制度の変更の予想 | 誤解を招く恐れがある。決まった内容だけを、出典つきで扱う。 |
| 「今年中に」「今のうちに」と期限で急がせるもの | 煽りになる。制度の期限がある場合も、事実として淡々と伝える。 |

## 4. 配信前に自分で確認する3点

- [ ] 10本のうち「これは話せる」と思えるものが5本以上あるか（得意な領域から外れていないか）
- [ ] 実際のお客様との会話で出た話題が混ざっているか（混ざっていなければ、最近の面談の話題に1〜2本入れ替える）
- [ ] 会社の規程に触れるネタが入っていないか（商品名・会社名・断定表現）
